# Architecture Decision Records (ADRs)

Settled decisions, one per file: `docs/adr/NNNN-short-title.md` (zero-padded,
incrementing). Read the relevant ADR **before changing the area it governs** so a
settled choice isn't relitigated. See [`_template.md`](_template.md).

An ADR is short and immutable once accepted; if a decision is reversed, write a
new ADR that supersedes the old one (and note it in both).
